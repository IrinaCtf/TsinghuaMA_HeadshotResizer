# TsinghuaMA_HeadshotFormatter — README
## 背景与用途
用于清华大学报考点硕士生网上确认时的“报名照片”预处理：将任意输入图片快速转换为150×200 像素、JPG、≤50KB的证件照，默认采用“等比放大后居中裁剪（cover）”保持构图自然，并自动搜索最合适的 JPEG 压缩质量以满足大小限制。

### 官方照片要求（请严格自查）
1. 本人近期拍摄，白色背景，正面、免冠、无妆、彩色头像电子证件照。
2. 宽 150 像素，高 200 像素。
3. JPG 格式，文件大小 ≤ 50KB。
4. 脸部无遮挡：头发不得遮挡脸部、眼睛、眉毛、耳朵或造成阴影，五官清晰可见。
5. 不得化妆；不得佩戴眼镜/隐形眼镜/美瞳；不得做任何修改（不得用 PS 等软件改变人像特征，如伤疤、痣、发型等）。
6. 务必谨慎上传符合全部要求的照片，否则可能影响审核。
本工具只做尺寸与体积压缩，不承担合规性审核；请在处理前后自行核对是否满足上列全部要求。

## 快速开始
1) 安装
```
pip install pillow
```
2) 使用
在同目录放入你的原始图片（任意格式均可）。命名为input.jpg。
```
python formatter.py
```
* 输入：input.jpg（可改为你的文件路径）
* 输出：out.jpg（JPG，150×200，≤50KB）
不裁主体模式：contain（等比缩放+留白填充到 150×200）

process_image("input.jpg", "out.jpg", mode="contain")
注：contain 模式四周会有白边，更适合不希望裁切人物边缘的情况。

## 常见问题
* 输出略超 50KB？极少数复杂图像在 50KB 内画质可能受限；可换更简洁背景或改用 contain 模式再试。
* 看起来发灰或偏色？个别相机色彩配置不同属正常；上传前可在预览中检查肤色与背景是否自然。
* 脸部被裁到？换用 mode="contain"，或更换原图构图（人物更居中、留出额头与下巴空间）。
